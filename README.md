# Bengaluru House Price Data Cleaning

## 📌 Overview
This project focuses on cleaning and preprocessing the Bengaluru house prices dataset using Python and Pandas. It includes data inspection, missing value handling, duplicate removal, and categorical data standardization.

## 🛠️ Technologies Used
- Python
- Pandas
- Jupyter Notebook

## 📊 Dataset
The dataset contains 13,320 records and 9 columns, including location, area type, property size, bathrooms, balconies, and price.

## ⚙️ Key Steps
- Loaded and explored the dataset using `head()`, `info()`, and `describe()`.
- Identified and handled missing values using mode imputation.
- Removed 530 duplicate records.
- Standardized text values in the `society` column.
- Validated the cleaned dataset.
